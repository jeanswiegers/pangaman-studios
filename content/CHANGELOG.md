# Changelog

All notable changes to this package are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - unreleased

### Added
- Eleven rules (CCR001–CCR011) for Domain Reload off and CoreCLR compatibility.
- Editor window with filters, search, details, Unity documentation links and a diff preview of each automatic fix.
- JSON and Markdown export; batchmode entry point with a CI exit code.
- Pro: apply one or all fixes with backup and revert, command-line apply/revert, precompiled DLL scan.
